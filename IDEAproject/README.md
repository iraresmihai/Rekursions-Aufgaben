# Rekursions-Aufgaben

Dieses Projekt enthält die fünf Teilaufgaben aus der Aufgabenbeschreibung:

1. Summe der Elemente
2. Zeichen zählen
3. Sortiertes Array
4. Wiederholungen entfernen
5. Klammern prüfen

Implementieren Sie alle Methoden in `RecTasks` rekursiv. Schleifen sind nicht
erlaubt. Beachten Sie auch die genaueren Anforderungen und Hinweise in
`../Aufgabenbeschreibung.pdf`.

Das Programm kann mit `./gradlew run` (Windows: `gradlew.bat run`) gestartet
werden. Alle Tests laufen gemeinsam mit `./gradlew test` (Windows:
`gradlew.bat test`).
